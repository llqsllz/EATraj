# Supplementary Materials

This directory contains the non-confidential supplementary materials referenced in the manuscript's Data Availability Statement. The project dataset, generated samples, checkpoints, and raw prediction arrays remain outside this release; the restricted simulation dataset is available from the corresponding author upon reasonable request.

## Contents

| File | Description |
|---|---|
| `optimization_settings.json` | Machine-readable data, model, and optimization settings for the final EATraj model. |
| `optimization_settings.md` | Human-readable explanation of the same settings. |
| `stratified_results.csv` | Full scene-level errors and threshold coverage across pre-defined strata. |
| `stratified_results.md` | Stratum definitions, eligibility rules, and a summary of the stratified results. |

These materials are also archived with a DOI in the Zenodo repository linked from the Data Availability Statement.
